# Mobile UX Enforcer

Mobile first.

## Rules
- Value within 30 seconds
- One-handed operation
- Large tap targets
- Conversational flows
- Progressive disclosure

## Avoid
- Dashboard overload
- Excessive menus
- Unnecessary clicks
- Hidden actions

Design for trust and clarity.
