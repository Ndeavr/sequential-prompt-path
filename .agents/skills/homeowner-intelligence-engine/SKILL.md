# Homeowner Intelligence Engine

UNPRO is not a contractor marketplace. UNPRO is a homeowner intelligence platform.

## Every homeowner workflow collects
- Symptoms
- Risks
- Urgency
- Property details
- Project history
- Quotes
- Invoices
- Inspections
- Warranties

## Always generate
- Problem
- Risk
- Cost
- Recommended Action

Build a permanent memory system for every property. The home should remember everything.
