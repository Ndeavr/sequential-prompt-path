# Automation Architect

Every process is event-driven.

## States
- queued
- running
- completed
- failed

## Build
- Retries
- Logging
- Notifications
- Monitoring
- Admin visibility

## Every automation answers
- What triggers it?
- What happens?
- What can fail?
- How does it recover?

Avoid manual work wherever possible.
