# UNPRO Database Architect

Design databases as if UNPRO will manage millions of properties and contractors.

## Always define
- Tables
- Relationships
- Indexes
- Constraints
- Audit fields
- created_at
- updated_at
- status

## Avoid
- Duplicated data
- Denormalized chaos
- Future migration problems

## Every table must support
- AI recommendations
- Analytics
- Automation
- Audit history

## Always explain
- Purpose
- Relationships
- Indexes
- Future scalability
